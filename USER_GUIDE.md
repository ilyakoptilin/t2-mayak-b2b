# Руководство пользователя (B2B-ассистент «Маяк»)

Данное руководство предназначено для менеджеров и разработчиков, использующих API ассистента для получения информации по регламентам B2B.

## 1. Запуск сервера
Убедитесь, что виртуальное окружение активировано, а база данных проинициализирована. Запустите FastAPI сервер командой:
```bash
uvicorn main:app --reload
```
Сервер запустится по адресу: `http://localhost:8000`

## 2. Работа через Swagger UI
Самый удобный способ взаимодействия с ассистентом — встроенный графический интерфейс.
1. Откройте в браузере: `http://localhost:8000/docs`
2. Найдите эндпоинт `POST /api/ask`.
3. Нажмите кнопку **Try it out**.
4. В поле Request body введите ваш запрос. Пример:
   ```json
   {
     "query": "Правила отмены КФО при расторжении договора"
   }
   ```
5. Нажмите **Execute** для отправки запроса.

## 3. Формат ответа
Система вернет JSON-объект, содержащий сгенерированный ответ и ссылки на источники из базы знаний.

**Пример ответа:**
```json
{
  "answer": "При расторжении Договора по инициативе Т2 в одностороннем порядке, по истечении 6 месяцев после получения Клиентом уведомления, Т2 вправе расторгнуть Договор и обнулить кредитный лимит.",
  "sources": [
    "Документ: Docs_content_B2B_matrica.pptx\nТекст:\n8.2. ПРАВИЛА ОТМЕНЫ КФО В СЛУЧАЕ РАСТОРЖЕНИЯ..."
  ]
}
```

## 4. Особенности формулировки запросов
- Система устойчива к опечаткам и регистру благодаря модели векторизации `e5-small`. Вы можете писать как заглавными, так и строчными буквами.
- При отсутствии точной информации в базе, ассистент прямо сообщит об этом, исключая риск галлюцинаций (выдумывания несуществующих тарифов).
