# Инструкция по установке (B2B-ассистент «Маяк»)

Данный документ описывает процесс развертывания бэкенд-части B2B-ассистента на локальной машине или сервере.

## 1. Системные требования
- **ОС:** macOS, Linux или Windows (WSL2)
- **Язык:** Python 3.10 или выше
- **LLM Провайдер:** Установленный локально [Ollama](https://ollama.com/)
- **Свободное место:** Минимум 5 ГБ (для весов эмбеддингов и LLM)

## 2. Установка Ollama и языковой модели
Платформа использует локальную модель Qwen для генерации ответов.
1. Скачайте и установите Ollama.
2. Запустите терминал и скачайте необходимую модель (например, Qwen 3):
   ```bash
   ollama pull hf.co/Qwen/Qwen3-8B-GGUF:Q4_K_M
   ```
   *(Убедитесь, что сервер Ollama запущен на стандартном порту 11434)*

## 3. Развертывание репозитория
Склонируйте проект и перейдите в директорию:
```bash
git clone https://github.com/ilyakoptilin/t2-mayak-b2b.git
cd t2-mayak-b2b
```

## 4. Настройка виртуального окружения
Создайте и активируйте изолированное окружение:
```bash
# Для macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Для Windows
python -m venv venv
venv\Scripts\activate
```

## 5. Установка зависимостей
Установите все необходимые Python-библиотеки из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

Для работы UI-тестов (опционально) установите браузеры Playwright:
```bash
playwright install
```

Среда успешно настроена и готова к инициализации базы данных.
